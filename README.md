# Subway Runner

A 3D endless runner game developed with Unity 6 and C#.

## 🎮 Play the Game

Play the game directly in your browser on Unity Play:

**[Play Subway Runner](https://play.unity.com/en/games/1790791c-b2bb-4079-a41b-c7d3537cc4de/new-folder)**

## 🕹️ Gameplay

Run forward, avoid obstacles, switch lanes, and jump to survive as long as possible!

## ✨ Features

- 3D endless runner gameplay
- Lane switching
- Jumping and obstacle avoidance
- Increasing challenge as you run

## 💻 Source Code

This repository contains C# scripts used in the development of Subway Runner.

The source code is publicly available for anyone interested in exploring how the game works.

## 🛠️ Built With

- Unity 6
- C#

## 📌 About

This project was created as a game development project to practice programming and learn more about building 3D games with Unity.
