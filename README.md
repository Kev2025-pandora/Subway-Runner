# Subway Runner

A 3D endless runner game developed using **Unity 6 and C#**.

## 🎮 Play the Game

Play directly in your browser on Unity Play:

**[Play Subway Runner](https://play.unity.com/en/games/1790791c-b2bb-4079-a41b-c7d3537cc4de/new-folder)**

## 🕹️ Gameplay

Run forward automatically, switch between three lanes, jump over obstacles, and slide to avoid barriers. Collect coins and power-ups while trying to survive as long as possible. The game becomes more challenging as your speed increases.

## ✨ Features

- **3D Endless Runner:** Procedurally generated track sections for continuous gameplay.
- **Three-Lane Movement:** Switch between lanes to avoid obstacles and collect items.
- **Jumping and Sliding:** Use different movement actions to overcome obstacles.
- **Dynamic Difficulty:** Game speed gradually increases over time.
- **Coin Collection:** Collect coins throughout the track.
- **Power-Ups:**
  - **Magnet:** Automatically attracts nearby coins.
  - **Giant Mode:** Temporarily increases the player's size and allows them to knock obstacles away.
- **Obstacle Variety:** Different obstacles require different movement strategies.
- **Screen Shake Effects:** Adds visual feedback during collisions and interactions.

## 💻 Source Code

This repository contains the C# scripts used to develop Subway Runner, including player movement, procedural track generation, obstacle spawning, coin collection, and power-up systems.

The source code is publicly available for anyone interested in exploring the game's implementation and learning from the project.
